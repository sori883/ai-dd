# 新方式では既存Intent・stateの移行を要件にしない

- 日付: 2026-09-07
- 状態: Accepted（ユーザー直接回答）

既存Intentと保存済みstateを新方式へ移して継続する必要があるかという質問に、ユーザーは
「既存は完全無視でいいです」と回答した。

新方式は新規Intentを対象とし、旧Intent・stateの移行、旧方式との互換性、旧版での作業継続支援を要件にしない。
新旧の二重運用や移行機能をマイルストーンの前提にしない。既存実装は有用な基盤のみ再利用候補として評価する。
旧Stage承認の部分完了修正や残る33 Stage実用化を、新製品完成の先行作業として要求しない。

[マイルストーン案](2026-09-07-minimal-product-milestones.md)および
[最小構成設計](../../design/okf-kdr-minimal-workflow.md)に残っていた既存dataの移行要否をこの回答で解決する。
新方式の保存・再開・更新の安全性は引き続き必要である。
この回答は、ユーザーの既存ファイルを実際に削除する指示や、未確定の新CLI・永続形式を実装する包括承認とは扱わない。
過去のRAM・実装履歴は保持する。
