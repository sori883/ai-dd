# 別cloneでの配置と担当割当の復旧を検討する

状態: Proposed。ユーザーは直前に説明したruntime割当・hook絶対pathの移転制約への対応を依頼した。
[対応案](../../design/clone-relocation-proposal.md)として、配置参照の更新と、旧処理の停止確認後の新担当への再割当を提示する。
同じIntent/Unitと成果は保持し、旧runtimeの丸ごとGit共有や遠隔処理の推測停止は採用しない案。
配置済設定の書換え範囲と新しい担当引継ぎ操作は重要な運用契約なので、方式確認後に実装計画を確定する。
この記録時点でコード・設定・Issue・PRは変更していない。以前の検証依頼を製品変更の包括承認に流用しない。
