# コマンドラインだけでインストールを完了したい

2026-09-14。ユーザーは公開したv0.1.1のAssetsが多く、どれを取得するか分からないと指摘し、
「理想はコマンドラインだけでインストール完結できれば良い」と希望した。

PR #201のmain反映と、公開v0.1.1の43添付を再確認した。
Go製`aidlc-install`は指定版の3runtimeと資材の取得・照合・配置を実装済み。
最初のインストーラーを利用者が選んで取得する部分が手動で残っている。

[具体案](../../design/command-line-install-entry-plan.md)では、sh/PowerShellの薄い取得入口を
追加し、OS・CPU判定、取得、照合を自動化した後に既存のGo製インストーラーへ渡す。
5CLIと43資材は維持し、利用者の手動選択をなくす提案である。
公開済み資材を削除すると現行インストーラーの取得先が欠けるため、無断で削除しない。

ユーザーが確定したのはコマンドで導入を完了したいという希望。
スクリプト方式、Go原則の初回取得に限る例外、実装・公開入口の追加はまだ提案段階。
製品コード・設定・Issue・PR・Releaseは変更していない。
