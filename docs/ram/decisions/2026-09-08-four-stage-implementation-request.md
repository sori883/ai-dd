## 確認中の選択

1. Intent・Unitの永続進捗をSpace配下でGit共有するか、PC内だけで管理するか。
   推奨はGit共有とし、担当AIの実行中情報はローカルへ分ける。
2. 並列Unitと独立レビューのAI起動を作業中の調整役AIが行うか、Go CLI自身がCodexを起動・回収するか。
   推奨は調整役AIが起動し、Go CLIが割当・結果・進捗を管理する方式。
