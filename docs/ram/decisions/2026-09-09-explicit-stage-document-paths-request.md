# ステージの入出力を実ファイル名で示す

ユーザーは、ステージMarkdownの `config.feature_knowledge` 参照について、実ファイル名を記載するよう依頼した。対象はoutputsだけでなくinputsも含む。

現在の定義には、固定名のRule・要件・計画・共有解析・構成図のpathと、`config.feature_knowledge`・`config.adr.refs`を参照する可変の文書一覧が混在する。利用者が別設定をたどらず、どのファイルを読み書きするか確認できることが要求である。

機能別Knowledgeと判断別ADRは、Intentによってファイル名・件数が異なる。これを共通ステージMarkdownの固定名へ統一するのか、Intentごとに確定した具体的path一覧を手順へ反映するのかは未確定。共有文書をIntent別へ移動することや、すべてのIntentで同じ機能文書を上書きすることは承認されていない。

この記録は要求と未確定事項を保存する。コード・配布定義・Issue・PRは変更していない。人間承認機能（Issue #146）はユーザー指示で中断中のまま。
