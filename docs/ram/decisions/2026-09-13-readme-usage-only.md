# READMEへ公開予定や準備状況を書かない

2026-09-13、ユーザーは、README冒頭の「0.1.0予定で、まだ公開前」という説明は不要であり、余計な情報を載せないよう指定した。

[初心者向けREADMEの編集方針](2026-09-13-beginner-readme-request.md)のうち、公開準備中を入口に明記する判断を、この依頼で置き換える。READMEは利用者が何を用意し、どう使うかに集中させる。冒頭の注記と公開前試用の説明を削除し、取得先を公開時期に依存しない案内へ整える。開発・配布の進捗や判断は開発者向け資料とRAMで扱う。

## 変更範囲と検証

[Issue #194](https://github.com/sori883/ai-dd/issues/194)。直接の修正依頼により、mainの`e5dbac888710bb0541b3b1f0eb2a8c2220d9948d`を基準に、親エージェント一人がREADME、本記録、RAM索引の3ファイルだけを編集する。過去RAMの本文を削除・上書きしない。

独立したread-only review、親のread-only finalで変更箇所・リンク・3ファイルの範囲・`git diff --check`を確認し、対象PRの既存CI成功後にsquash mergeする。文書だけなのでGo test/buildをローカルでは実行しない。取り消しは文書差分のrevertで行える。

公開時期の説明をREADMEから省く依頼であり、製品コード・配布設定・初回バージョン・ライセンス選択・実リリースの判断は変更しない。
