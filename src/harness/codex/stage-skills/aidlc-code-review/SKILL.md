description: reviewerが固定した差分を要求と規約の二つの観点で独立確認する。
---

受け取ったbase/headまたは対象差分が有効か確かめ、要求・計画と規約を確認する。要求の欠落、誤実装、範囲超過を要求観点へ、文書化された規約違反を規約観点へ分ける。命名、重複、責任分散、不要な抽象はheuristicとして根拠と影響を示し、規約違反と混同しない。指摘には位置、再現条件、利用者への影響、修正方向を添える。単なる好みやtoolで確認済みの項目を繰り返さない。既存reviewerが両観点を担当し、新たな子の起動や実装変更をせず、各観点の結果と確認できなかった範囲をメインAIへ返す。

現在の工程・許可担当・Sensor・人間承認に従う。担当追加や子の独自起動をこのskillから許可しない。同じrootのwriterは一人に保つ。共有文書の保存はメインAIが [aidlc-okf](../aidlc-okf/SKILL.md) を読み、aidlc memoryで行う。担当は本文案と根拠を返す。
