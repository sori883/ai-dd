# Conventions
- Never guess material ambiguities; ask the user.
- Before implementation, present a plan and obtain explicit user approval.
- Place design, milestone, compliance, development, and operations documents under `docs/`.
- Place development source and development-target documentation under `src/`.
- Use Go; standard library first. External Go modules require justification and explicit approval.
- Do not access `work/` without special instruction.
- Prefer Context7 for external library/API specifications and examples.
- Start Codex sessions by activating the repository in Serena and reading Serena initial instructions.
