# Task Completion
- Create a GitHub Issue before implementation.
- Implement only after explicit approval of the plan.
- For Go changes: format with `gofmt`; run targeted tests during iteration; run `go test ./...` and `go test -race ./...` before completion when a module exists.
- Review the diff and run `git diff --check`.
- Create a PR for merge work and link it to the Issue.
- After PR merge and completed work, close the linked Issue.
- Do not add external Go modules without separate explicit approval.
